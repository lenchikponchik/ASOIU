# ASOIU
Антонов Леонид ИУ5-22Б. Вариант 3: `car_brand` → `car`.

## Состав проекта

| Папка | Содержание |
|---|---|
| `sem1` | Анализ квалификации Гран-при (массивы, пузырьковая сортировка, статистика) |
| `sem2` | Разреженные матрицы: COO, LIL, CSR |
| `sem3` | CSV + SQLite + операции реляционной алгебры |
| `sem4` | Классы-фигуры, дженерик-матрица, собственный список и стек, quicksort |
| `sem5` | Внедрение зависимостей (DI): конструктор / свойство / метод, Pure DI, DI-контейнер, антипаттерны |
| `sem6` | Рефакторинг, чистый код, SOLID/DRY/KISS/YAGNI, паттерн «Стратегия» |
| `sem7` | Тестирование: xUnit, Moq, TDD/BDD; `sem7.Tests/` — модульные тесты |
| `ДЗ1` | Расстояние Дамерау–Левенштейна |
| `ДЗ2` | Консоль SQLite, вариант 3: марки автомобилей и автомобили, Fluent-отчёты |
| `ДЗ3` | EF Core Code First + LINQ + WinForms, вариант 3 |

---

## Требования

- .NET SDK 8+ (`dotnet --version` должна показать версию)
- Windows — только для ДЗ3 (WinForms)

Проверить наличие SDK:
```
dotnet --list-sdks
```

## Быстрый старт

### Открыть в IDE

Открыть файл `ASOIU.slnx` в **Rider** или **Visual Studio 2022+** — все проекты подтянутся автоматически.

### Собрать всё сразу

```
dotnet build ASOIU.slnx
```

## Запуск семинаров

Каждый семинар — консольное приложение, запускается командой:

```
dotnet run --project sem1/sem1.csproj
dotnet run --project sem2/sem2.csproj
dotnet run --project sem3/sem3.csproj
dotnet run --project sem4/sem4.csproj
dotnet run --project sem5/sem5.csproj
dotnet run --project sem6/sem6.csproj
dotnet run --project sem7/sem7.csproj
```

**sem3** при первом запуске читает `dep.csv` и `dev.csv` из той же папки — они уже лежат там.

**sem5** создаёт файл `sem5_log.txt` в текущей директории (демонстрация FileLogger).

## Запуск домашних заданий

### ДЗ1 — Расстояние Дамерау–Левенштейна

```
dotnet run --project ДЗ1/EditDistance.csproj
```

Программа попросит ввести две строки и выведет расстояние.

### ДЗ2 — Консоль SQLite (авто, вариант 3)

```
dotnet run --project ДЗ2/Dz2.csproj
```

- При первом запуске база `cars.db` создаётся автоматически.
- Если рядом лежат `car_brands.csv` и `cars.csv`, данные импортируются из них.
- Навигация по меню цифрами. Пункт «6 → Отчёты → 4» сохраняет отчёт в файл.

### ДЗ3 — ASP.NET MVC + EF Core (авто, вариант 3)

> Работает на Windows, Linux и macOS.

```
dotnet run --project ДЗ3/ДЗ3.csproj
```

После запуска открыть в браузере: **http://localhost:5000**

- При первом запуске создаётся база `cars_ef.db` и автоматически заполняется начальными данными (4 марки, 12 автомобилей).
- Навигация через шапку: **Марки** / **Автомобили** / **Отчёты**.
- Удаление марки заблокировано, пока к ней привязаны автомобили.
- Раздел «Отчёты» содержит три LINQ-вкладки: полный список, количество по маркам, средняя мощность.

Отчёт по работе: `ДЗ3/АнтоновЛ_АСОИУ_ИУ5-22Б_ДЗ3.docx`
