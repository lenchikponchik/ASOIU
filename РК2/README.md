## Структура задания

| Файл / папка | Назначение |
|---|---|
| `concept_map.md` | Концептуальная карта в текстовом формате (граф понятий) |
| `concept_map.dot` | Граф в формате Graphviz (можно визуализировать онлайн на graphviz.online) |
| Опрос `.xlsx` | Заполняется **лично** в соответствии с инструкцией из архива задания |

## Как просмотреть граф

Скопировать содержимое `concept_map.dot` в [graphviz.online](https://graphviz.online/) или установить Graphviz и выполнить:

```bash
dot -Tpng concept_map.dot -o concept_map.png
```
